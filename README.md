# **AVPlayer - IOS**

### **项目介绍**
AVPlayer - IOS 是基于 iOS 平台的音视频处理项目，借助 AVFoundation、Core Video 和 Metal 等框架，实现了音视频从采集、编码、封装、解封装、解码、渲染的流程。<br>

### **项目结构**

#### **Base 模块**
项目的基础部件，包含以下源文件：<br>
- MediaBase：定义媒体文件类型。<br>
- WeakProxy：实现了一个弱代理相关的功能，用于避免循环引用等情况。<br>

#### **Capture 模块**
负责音视频的采集功能，具体源文件如下：<br>
- AudioConfig：配置音频采集相关的参数。<br>
- AudioCapture：初始化方法、开始采集、停止采集、音频采集数据回调和错误回调的接口。<br>
- VideoCaptureConfig：配置视频采集相关的参数和设置。<br>
- VideoCapture：初始化方法，视频采集数据回调和错误回调的接口，开始采集和停止采集的接口。。<br>

#### **Encoder 模块**
用于对采集到的音视频进行编码处理，包含以下文件：<br>
- AudioEncoder：主要是有获取音频编码码率、编码的接口、音频编码数据回调和错误回调的接口。<br>
- AudioTools：可能包含一些音频处理的工具方法或辅助函数。<br>
- VideoEncoderConfig：配置视频编码相关的参数和设置。<br>
- VideoEncoder：获取视频编码配置以及视频编码数据回调和错误回调的接口，编码、刷新重建编码器、清空编码缓冲区的接口。<br>

#### **Decoder 模块**
负责对编码后的音视频进行解码操作，有以下源文件：<br>
- AudioDecoder：音频解码数据回调、错误回调的接口解码的接口。<br>
- VideoDecoder：视频解码数据回调和错误回调的接口，解码和清空解码缓冲区的接口<br>

#### **Demuxer 模块**
用于分离音视频流，具体如下：<br>
- DemuxerConfig：配置解复用相关的参数和设置。<br>
- MP4Demuxer：初始化方法，获取解封装器信息或者状态，执行开始/取消读取数据、拷贝音频/视频采样数据的接口。<br>

#### **Muxer 模块**
用于将音视频流进行合并，包含的文件为：<br>
- MuxerConfig：配置复用相关的参数和设置。<br>
- MP4Muxer：获取封装配置以及封装错误回调的接口，开始写入封装数据、取消写入封装数据、添加封装数据、停止写入封装数据的接口。<br>

#### **Render 模块**
负责将解码后的音视频进行渲染展示，源文件包括：<br>
- AudioRender：初始化接口，音频渲染数据输入回调和错误回调的接口，获取声道数和获取采样率的接口，以及开始渲染和结束渲染的接口。<br>
- MetalView：基于 Metal 框架的视图相关实现，用于视频渲染的视图展示。<br>
- ShaderType：定义了渲染所需的着色器类型等相关声明。<br>
- render：具体的 Metal 着色器代码文件，用于处理视频渲染的图形相关操作，类似 OpenGL 的 shader。


### **依赖说明**
项目依赖以下框架：<br>
- AudioToolbox：提供音频采集、播放等功能。<br>
- AVFoundation：提供视频采集、播放等功能。<br>
- CoreMedia：提供基础的媒体数据结构和处理机制。<br>
- CoreVideo：用于处理视频数据，如图像格式转换、视频帧处理等。<br>
- Metal：用于实现视频渲染。<br>
